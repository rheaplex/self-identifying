Self-Identifying
================

Rhea Myers, 2025.

PostScript Quines that generate a cryptographic identity from themselves
and use it to sign the image that they generate.

Notes
=====

macOS Preview.app mangles the images in bitmap/graymap/pixmap.
They show OK in other PDF viewers, notably Acrobat.

The document size is ANSI C.

Where you see any strange constants being applied to positions,
this is a fudge to allow for the font ascender height,
particularly on the first row of multi-line text where it must align with the top margin.

The `scale` in statement.pdf is to make the text fill the available space.

Generally, where a number is strange it is there to make things fit.
